2FLY DRIVE-IN — TEST BUILD
========================
Scope: independent main-navigation feature, I Was Away only. Existing VHS files and route are unchanged. Entry: pages/drive-in.html. Main navigation entry: pages/site-overhaul.html.

MEDIA
The title, poster and 1080p MP4 are verified against data/projects.json (id: away). Browser playback reports 1920x1080, 145.1 seconds. Only the selected video source is assigned after Play. object-fit:contain preserves the full frame. The steel opening is wider than 16:9, so intentional side bars preserve the original video.

IMPLEMENTATION
No build step or new runtime dependency. Serve the repository as static files over HTTP; open pages/drive-in.html. External Wix media requires network access. Upload the changed files at their existing relative paths. Do not replace the repository with this patch archive.

Controls: Play/pause, seek, volume, mute, fullscreen, replay, Theater Mode, collapsible mobile program. Drag knobs vertically or horizontally; keyboard arrows adjust them, Home/End select extremes. Focus the video viewport for Space/K (play), M (mute), F (fullscreen), left/right (seek 5 seconds). Escape exits Theater Mode.

Tuning previews FM positions during dragging, then snaps to the nearest available station on release; keyboard tuning settles after 450ms. The one station is permanently 88.1 FM. Retuning the same station never resets playback. Previous/next and pagination are disabled for this one-video release. No other catalogue videos or invented titles are loaded.

The station list in js/drive-in.js is deliberately limited to the approved test. The list/rendering supports expansion and five entries per program page, but multi-video navigation and page shuffle are NOT validated by this single-video test. Preserve assigned frequencies when expanding.

AUDIO
Reuses js/site-audio-ownership.js and its same-origin BroadcastChannel. Actual global music and Drive-In video pause each other across same-origin tabs. Local media is also paused when Drive-In starts. No ambient sound is loaded. Browser autoplay restrictions still apply; playback starts from an explicit user action. This test checks playback state and source handoff, not subjective speaker output.

Tablet/phone CSS deliberately reflows radio and program. At <=700px the program is collapsible beneath the compact radio. Asset-space masks must follow their parent layer transforms; do not stretch the reference masks over different viewport sizes.

Optimized runtime WebP artwork totals approximately 1.02 MB. Genuine alpha on structure, dashboard, radio, knob and paper. The full screenshot is not used as a webpage background. The reference composite is a browser screenshot only.
