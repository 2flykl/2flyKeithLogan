2FLY DRIVE-IN — ANIMATED BUILD
=============================
CURRENT RELEASE
Separate main-navigation destination: pages/drive-in.html. Includes I Was Away (88.1 FM), Streams (88.3 FM), and Thru the Fire (88.5 FM), using the verified original video/poster URLs from data/projects.json. VHS files and route are preserved.

BACKGROUND VIDEOS
All six user-supplied loops are included in assets/drive-in/loops. Weighted random selection: Kling 75%; each other clip 5%. Selection runs on arrival, then every 45 seconds of visible playback. A repeat selection leaves the current clip running. A different selection loads into a second muted slot and fades over the current clip for 1.8 seconds only when ready; the outgoing source is then released. The clips loop between selections. Weight is a probability per selection, not a guarantee for any short visit.
Only the selected clip is downloaded initially; a second source loads during a transition. The entire catalogue is not prefetched. Original uploaded encodes are retained, approximately 34.9 MB total; individual files are approximately 2.5–12.8 MB. The videos' original motion, exposure changes and loop seams remain as supplied. Kling receives most of the weight because it is the most restrained.
All exterior video is muted and volume zero. Reduced-motion preference shows the still and downloads no loop on initial load. Hidden documents pause background playback; a failed clip falls back to the still/current clip and is excluded from later selections for that visit. The static scene is always beneath the video layers. No visual layer intercepts player clicks.

CONTROLS
After playback starts, movie controls are hidden while the pointer is away from the movie, whether playing or paused. Hover reveals them and they stay visible while hovered. Dashboard interactions do not reveal them. Keyboard focus reveals accessible controls. On touch devices, tap the screen to show controls for 4.5 seconds; tapping outside hides them. The radio remains available for playback, tuning and volume. Fullscreen, volume, seeking and mute remain functional.

DELIVERY
This is a static website patch. No package installation or build step is required. Extract the implementation ZIP into the existing repository while preserving relative paths. Do not replace unrelated site files. Serve over HTTP, then open pages/drive-in.html. Wix movie media requires an internet connection. All six background MP4 files are bundled and explicitly tracked despite the repository's general MP4 ignore rule.
Production is not deployed. Review branch: feat/2fly-drive-in; draft PR #37.

ARTWORK AND DEPTH
Six independent photographic artwork layers: exterior, steel screen and sign, transparent dashboard, chrome radio, separate knobs, blank paper with live typography. The revised structure has no concrete footings or central lower bracing. The two dark outer posts use a depth mask fading below 82%–94% of structure height. Desktop stage: width min(80vw,1280px), top 5.5%, height 68%; opening stage-relative left 7.8%, top 18.2%, width 84.4%, height 61.2%. Tablet and mobile reflow in css/drive-in.css. Exterior still and both video slots share the same cover placement and object position. The minor source aspect-ratio variations are handled by cover, while the fixed UI layers keep their positions.
