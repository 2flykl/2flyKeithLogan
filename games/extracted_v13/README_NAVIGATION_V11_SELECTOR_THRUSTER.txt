2fly Universe — Navigation V11: Selector + Direct Thruster

BASE
- Uses the approved V7/default-distance galaxy framing and spacing.
- Keeps default click travel scale; left click no longer moves the camera by itself.

MOUSE CONTROL MODEL
- Left click on galaxy/orbit object/star: select only.
- Gray selector circle follows the selected world-space target.
- Left click empty space: clear selection.
- Left hold + drag: true orbit. Inside a galaxy, the galaxy center is the fixed orbit axis and orbit radius is preserved.
- Right click: short forward thruster boost.
- Right hold: immediate continuous forward thrust.
- Long right hold: gradually progresses into warp after an extended hold.

THRUSTER PRIORITY
- If a target is selected, thrust travels toward the selected target.
- If no target is selected, thrust follows the live mouse direction naturally.
- Any negative/backward velocity along the intended thrust vector is canceled before forward thrust is applied. There is no pull-back/wind-up motion.
- Galaxy local gravity/correction does not oppose active thrust.

DEEP SPACE SAFETY
- The outer-universe return field activates only when there is no selected target.
- With no target, deep-space travel is progressively redirected toward the galaxy cluster so the player cannot remain lost in black space.
- A selected galaxy/target temporarily overrides auto-return so intentional travel is respected.

GALAXY PERIMETER
- Removed the persistent camera/screen-edge color overlay.
- Each galaxy now has its own faint, world-space colored perimeter shell.
- The perimeter shell becomes active for the galaxy currently being occupied and remains physically attached to that galaxy.

CONTENT
- Single-click selection does not activate content.
- Existing double-click engagement behavior remains for playable/interactive items.
