2FLY UNIVERSE — NAVIGATION STYLE V7
FREE GALAXY RESIDENCY + DELIBERATE CONTENT INTERACTION

CHANGES
- Removed the galaxy center snap/recalibration behavior.
- Galaxy residency now uses separate enter/exit thresholds (hysteresis) to prevent perimeter flicker.
- Local galaxy influence is deliberately weak. Free floating is preserved.
- Outward coasting receives only very slow atmospheric resistance, stronger near the edge; it no longer throws the user out.
- Right-mouse thrust can intentionally overcome the local atmosphere.
- Added a faint galaxy-color perimeter atmosphere while inside a galaxy. It uses a slow cascading pulse and remains transparent so distant galaxies are still visible.
- Entry/exit presentation is shorter than V6.
- Entered galaxy title is substantially larger and easier to read.
- Single click on an orbit item: highlight + identify only. Camera does not zoom or travel.
- Double click on an orbit content item: engage/open content.
- Passing near/through orbit objects does not engage content.
- Selection highlight persists briefly to allow the label to be read.
- Selection is ignored by the existing thrust-click suppression while actively thrusting.
- Existing open-universe navigation, right-mouse propulsion, wormholes, hyperlapse, and outer-universe return field remain intact.

INTERACTION
Open space: click-to-carrot movement / right mouse hold to thrust.
Inside galaxy: free navigation with weak atmospheric resistance.
Orbit item: single click = identify; double click = engage.
