STREAMS OVERHAUL — BALANCED VARIETY + PHYSICS

Changes in this pass:
- Floating gameplay objects are slightly enlarged for readability and fun.
- The object pool now uses 21 different stream items instead of repeating the same few assets.
- A shuffle-bag selector reduces immediate visual repeats.
- Main-route generation now uses controlled cadence: normal jumps, occasional challenge gaps, and regular wider breather platforms.
- Optional side platforms are limited by cooldown so the screen does not become overcrowded.
- Reward tokens no longer appear on every platform; hazards also use controlled density.
- Landing impact now transfers a small amount of momentum into lighter floating objects.
- Jumping off lighter objects creates visible recoil and slight sink response while preserving player control.
- Visual object width and collision width stay unified.
