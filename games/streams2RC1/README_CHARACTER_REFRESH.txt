STREAMS OVERHAUL · CHARACTER REFRESH

What changed
- Rebuilt the playable character using the updated two-poses-per-sheet source set.
- Converted each pose into an isolated fixed-canvas gameplay frame.
- Added the newer states into the build: expanded idle, traverse/run, jump launch, rise, apex, descent, landing, recovery/ready, balance, slip/fall, and victory.
- Included the roomy source sheets inside assets/source_sheets/character_refresh so you can inspect the art used for this pass.

How to run
1. Extract the ZIP.
2. Double-click START_STREAMS_CHARACTER_REFRESH.bat
3. The browser should open the refreshed build.

Notes
- This remains a separate build and does not overwrite your prior STREAMS folders.
- The first BAT launch attempts to download the original soundtrack into assets/audio/streams_song.mp3.
- If the download fails, the game still opens.
