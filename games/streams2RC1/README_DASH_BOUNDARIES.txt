STREAMS OVERHAUL — DASH + TRUE BOUNDARIES

Changes in this pass:
- Double-tap then hold Left/Right (or A/D) to engage a momentum dash.
- Jump is Up Arrow or Spacebar.
- Dash velocity carries into jumps for longer gaps.
- Platform collision now matches the visible object's full rendered width.
- Removed the extended vibration/boundary markers.
- Platform art uses the original object set only (not the neon music sheet) and is toned down with less saturation/brightness for a more grounded look.
- Small objects are genuinely small landing spots; large objects provide room to run/dash.
- Sinking/buoyancy behavior remains object-specific.
- Value tokens switch more slowly, and slow further when the player is close enough to aim.
