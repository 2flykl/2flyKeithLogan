# Thru the Fire — Visual RC

Extract the entire ZIP, then open index.html in a current desktop browser. Keep all files together. No install or internet connection is required. Click ENTER THE HOUSE to enable sound. On Windows, use Extract All before opening the game.

Controls: Left / Right turns through eight views, or changes focus in a dual-choice view. Up saves the focused item or takes a marked exit. Touch controls are included. One saved item per room; medium and heavy items retain their original time penalties. Exit routes activate halfway through the countdown. Exit returns to the title when played standalone; the existing parent closeExperience message is preserved for an embedded game.

The six original rooms, scenario data, time limits, randomized choices, discovery logic, and win/failure rules are retained. See VISUAL_RC_REPORT.md for changes and test scope.

This is a separate review candidate. The supplied original ZIP has not been modified. This package has not been deployed to GitHub or the live website.
