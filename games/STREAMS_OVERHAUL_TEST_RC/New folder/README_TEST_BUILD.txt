STREAMS OVERHAUL — FIRST LOCAL TEST

1. Double-click START_STREAMS_OVERHAUL.bat
2. Your browser should open the new build at http://localhost:8787/
3. Controls: A/D or Left/Right to move. W / Up / Space to jump.
4. This folder is standalone and does NOT overwrite the original STREAMS game.

What changed in this test:
- New 330-character animation set integrated.
- New generated VALUE art: pennies, money stacks and reward graphics.
- New generated ATTENTION art: blue energy / social attention orbs.
- New generated MUSIC/MEDIA asset sheet included for continued art expansion.
- Layered water textures and procedural current rendering.
- Riverbank framing, stronger depth, wake/light treatment, stage reveal.
- New integrated HUD for Value / Attention / Flow / Stage progress.
- Flow multiplier driven by successful landings and collection chains.
- Platform behavioral types: stable, fast, boost, fragile, high-value.
- Value/Attention gameplay identity scoring at the end of a run.
- Camera tracking, particles, stronger waterfall failure presentation.
- Responsive keyboard and touch controls.
- Source asset sheets included under assets/new for follow-up refinement.

NOTE: The soundtrack is streamed from the same online source as the original build, so music requires internet access. Gameplay itself is local.
