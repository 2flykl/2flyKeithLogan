2FLY UNIVERSE CANONICAL PATH

The only supported repository path is:

games/2fly-universe/

Rules:
- all lowercase
- hyphen between 2fly and universe
- no capitalization variants
- all site navigation, playable-experience links, iframe/modal launchers, build scripts, and asset references must resolve to this same folder
- run `npm run verify:path` before building if there is any doubt
- `npm run build` now performs the path check automatically before compilation

If Windows needs a capitalization-only correction, rename through a temporary unrelated name first, then rename to exactly `2fly-universe` so Git records the change.
