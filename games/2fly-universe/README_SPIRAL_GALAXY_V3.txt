2FLY UNIVERSE — SPIRAL GALAXY REBUILD V3

This build changes the ACTUAL WebGL galaxy renderer. It is not a generated image or a flat reference mockup.

PRIMARY CHANGES
- Removes the giant green spherical nebula/plate presentation from the Playable Frontier.
- Rebuilds the showcase galaxy as a thin five-arm stellar/dust disc.
- Doubles down on GPU particles for the visible spiral silhouette.
- Adds brighter white/gold stellar clusters inside teal spiral arms.
- Adds dark gaps between arms so the spiral reads clearly from a distance.
- Replaces the thick volumetric gas sphere with two very thin procedural spiral-veils.
- Rebuilds the center as a compact luminous nucleus + rotating accretion/stardensity disk + concentric energy rings.
- Reduces global white orbit/groove clutter from 15 lines to 6 on the flagship galaxy.
- Keeps the full Three.js engine, existing planets, camera, navigation, boundaries, and content systems.

HOW TO RUN
Extract to a NEW folder, then double-click:
START_SPIRAL_GALAXY_V3_GPU_SAFE.bat

Expected URL: http://127.0.0.1:8090
