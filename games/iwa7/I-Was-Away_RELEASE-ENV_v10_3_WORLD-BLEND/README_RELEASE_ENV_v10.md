I WAS AWAY — RELEASE ENVIRONMENT v10

Purpose
This build is a release-environment candidate, not another placeholder pass. It keeps the Firefly character / boomerang systems and replaces much of the low-poly field dressing with the environment art assets created for I Was Away.

Environment changes
- Asset-driven 4-variant trees arranged as crossed planes for better orbit depth.
- Asset-driven rocks, grass clumps, wildflowers and meadow dressing.
- Real meadow/path/rock ground textures extracted from the environment art sheet.
- Softer atmospheric clouds, haze, sun halo, distant ridges and dust.
- Deterministic art-directed layout with a clear gameplay/catch corridor.
- Ground tonal variation to reduce a tiled/game-prototype appearance.
- Existing orbit smoothing, character states, music, boomerang Track Cam and gameplay retained from the boot-fixed base.

Constraint
The environmental props are high-quality 2D/2.5D art assets rather than full photogrammetry/AAA 3D meshes. Cross-plane trees and layered field dressing are used to preserve quality and performance in Three.js while supporting camera orbit.
