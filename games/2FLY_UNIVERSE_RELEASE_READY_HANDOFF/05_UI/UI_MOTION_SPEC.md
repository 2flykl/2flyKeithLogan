# UI / Motion Specification
- UI floats over space; avoid permanent large panels.
- Progressive disclosure by camera distance.
- Selection: subtle reticle + object name + type.
- Approach: 600–1200ms eased camera motion; cinematic fly-to longer only for deep links.
- Reduced motion: <=200ms fade/scale, no forced flight.
- Star placement must require explicit final confirmation.
- Media overlays dim space but preserve visible spatial context.
- Esc/Back closes one layer at a time.
- Mobile primary controls remain thumb-reachable and respect safe areas.
