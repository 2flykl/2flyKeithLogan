TIGER CALL: STILL STANDING — PLX RELEASE BUILD
================================================

WHAT THIS IS
A self-contained browser rhythm/playable experience built around the supplied Tiger Call (Still Standing) video.
The original performance runs as the living stage while the game layers a body-cam/first-person rhythm HUD, animated band overlays, section-specific mechanics, scoring and HYPE on top.

PLAY
1. Unzip the folder.
2. Double-click index.html in Chrome/Edge/Firefox.
3. Press ENTER THE FORMATION.
4. Controls: Arrow keys or A/W/D/S.
5. On touch devices, use the four on-screen buttons.
6. ESC pauses.

GAME DESIGN
- Double-time rhythm feel: ~198 BPM chart grid over the original performance.
- One 4-button language throughout the whole experience.
- Camera/section progression:
  COUNT-IN -> DRUMLINE -> BRASS -> FIELD FORMATION -> CALL & RESPONSE -> SHOWTIME -> TIGER CALL.
- Tap notes, held notes, chords, pattern bursts and formation sequences.
- Performance-driven HYPE meter.
- Visual showmanship escalates as HYPE rises.
- First-person hands/instrument silhouette changes by section.
- Animated Tiger musicians stay active around the formation instead of acting like static wallpaper.
- Tiger Call super: at near-max HYPE, slam all four inputs in rapid succession.
- Final letter grade and performance stats.

IMPORTANT NEXT LEVEL WITH STEMS
This one-shot uses the supplied MP4 master. If individual stems are added later, the engine can map accuracy to actual instrument layers: drums/brass/bass can duck, solo, build, remix, or drop out according to player performance. The current visual/game architecture is already sectioned for that upgrade.
