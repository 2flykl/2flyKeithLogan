TAMBOURINE TEMPEST
------------------
The Note Rifle slot now presents as TAMBOURINE TEMPEST, using the uploaded/new art direction while preserving the proven rapid-fire underlying gameplay behavior for this pass.

The existing note_rifle internal id is intentionally retained so the current projectile/audio/gameplay code remains stable while the presentation is upgraded.
