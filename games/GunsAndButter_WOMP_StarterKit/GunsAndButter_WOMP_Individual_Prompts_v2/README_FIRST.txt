GUNS & BUTTER — INDIVIDUAL WOMP PROMPTS v2

IMPORTANT CHANGE:
Every prompt now tells ChatGPT to use the pasted image as DESIGN REFERENCE ONLY.

That means the source image may contain:
- screenshot UI
- labels/text
- cropped pieces
- projectile/fire effects
- low resolution
- bad perspective
- AI artifacts
- distorted geometry
- missing areas

Those defects should NOT be copied into the final weapon.

Instead, ChatGPT should infer the intended design, reconstruct a clean canonical weapon, and then create all animation/FX/model-reference assets from that clean canonical version.

WORKFLOW
1. Open the relevant WOMP text file.
2. Copy/paste the full prompt back into ChatGPT.
3. Upload the best available image of that WOMP.
4. The image does NOT have to be perfect.
5. ChatGPT should reconstruct the intended weapon before creating the final sheets.
