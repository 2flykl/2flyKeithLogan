Extract the entire ZIP. With Node.js installed, run PLAY.cmd, then open
http://127.0.0.1:8772 in Chrome or Edge. Keep the terminal open while playing.
Alternatively serve this folder with any static HTTP server supporting video byte ranges.
Do not double-click index.html: MIDI fetch requires HTTP.

Controls: LEFT / DOWN / RIGHT / UP = I / O / P / 9 or arrow keys.
Touch: tap the matching paw. Escape or pause button pauses/resumes.

Production MIDI, media clock, lane order and scoring are unchanged.
This active build has tap judging only, with no hold scoring or letter grades.
Its preserved chart starts DOWN, DOWN, RIGHT.

The package contains only runtime dependencies, not unused legacy assets.
QA covers desktop Chromium and mobile touch emulation; physical iOS/Android
and subjective audio listening are not certified. Nothing was deployed.
