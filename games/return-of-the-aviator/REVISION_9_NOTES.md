# Return of the Aviator — Revision 9

Core fixes in this build:
- Freefall scene now has active vertical environmental motion and layered parallax.
- Runway scene rebuilt as a forward/reverse moving runner track instead of a static board.
- 2Fly secures the Tonearm item mid-run, turns back toward camera, and retreats while the boss emerges.
- Vehicle scene now uses a standard hero car instead of the Piano Tank.
- Driving route has more oncoming bot vehicles, fewer flying enemies, and power-up drops.
- Added a charge-based power burst system collected from certain kills and pickups.
- Enemy roster now mixes different sizes and not every bot shoots.
- Removed in-scene enemy labels to reduce visual clutter and unwanted text.
- Boss fight retains upward aiming and floating platform phase.
