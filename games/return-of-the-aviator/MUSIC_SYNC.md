# Too Fast — Dynamic Cue Director

Source: https://static.wixstatic.com/mp3/85e419_62dfb4b5acfc4747a02ad9eaeb643f29.mp3

The game reads the audio element's actual duration at runtime.

Default cue proportions:
- 0%–7.5%: plane swarm / destruction / jump
- 7.5%–33%: freefall battle
- 33%–56%: runway escape
- 56%–79%: vehicle pursuit
- 79%–98.5%: Algorithm Air Boss
- final ~1.5%: resolution/outro

These are derived at runtime rather than tied to one fixed MP3 duration.
