TIGER CALL / STILL STANDING

PRIMARY LAUNCH
Extract the entire ZIP, then double-click index.html. No installation, server,
terminal commands or Internet connection is required.

FALLBACK
Right-click index.html, choose Open with, then Google Chrome or Microsoft Edge.
Keep index.html beside its src and assets folders. Do not run from inside the ZIP.
A BAT or GPU-specific launcher is not required for this build.

CONTROLS
Left / Down / Right / Up: arrow keys or I / O / P / 9.
On touch screens, tap the matching paw. Escape or the pause button pauses.
Use RUN IT BACK after the performance to replay.

BROWSER NOTE
Use current Chrome or Edge. Sound begins when you press START TIGER CALL.
The same files also work on a static HTTP host.

PLAY SETTINGS
Classic keeps the original forgiving windows. Precision uses tighter judgments.
Scroll speed changes only cue travel, not the music or MIDI.
If consistently late, increase Input offset; if early, decrease it.
Visual offset adjusts only the cue display. Start at zero and make small changes.
Results separate hit coverage from weighted timing accuracy. Return has a two-second countdown.


SUSTAIN NOTES
When a paw has a glowing ribbon and HOLD label, keep its key or touch pressed until the trail ends.
Six long notes follow the original MIDI durations. Sustain completion is reported separately; head scoring is unchanged.
After pausing during a hold, press the matching key or paw again when play resumes.

PRESENTATION
Centered animated title, left score, right crowd-hype meter, and supplied tiger stadium title artwork.
Reduced-motion preferences disable decorative header animation.
