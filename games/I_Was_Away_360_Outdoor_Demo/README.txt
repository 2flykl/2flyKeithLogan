I WAS AWAY — OUTDOOR 360 DEMO

WHAT THIS VERSION CHANGES
- The test space is now an outdoor open environment instead of a tight interior panorama.
- It uses a broad ledge, lake, distant skyline, mountains, open sky, and foreground grass so you can better evaluate the outside panoramic concept.

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Internet is required only for loading the Three.js library from its CDN.

CONTROLS
- Drag mouse: look around 360°
- Mouse wheel: zoom / field of view
- THROW BOOMERANG: sample 3D throw arc
- AUTO ORBIT: automatically rotate camera
- PLACEHOLDERS: show/hide the simple player/instructor stand-ins
- RESET VIEW: return to the default camera angle

WHAT TO JUDGE
- Does the outside/open-space feeling work better for your game?
- Does the panoramic method feel usable for the boomerang gameplay concept?
- Do you want the final environment to lean more toward valley/lake, mountain overlook, city overlook, or grassy field?

NOTE
This is still a proof-of-concept browser lab, not the final production art. The environment is intentionally broad and readable so you can judge the technique first.
