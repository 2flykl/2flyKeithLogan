BLACK & GIFTED — Museum RC No-Server Build

This build DOES NOT use Python, localhost, a web server, or port 8765.

1. Extract the ZIP completely.
2. Double-click START_BLACK_AND_GIFTED.bat
   OR simply double-click index.html.
3. Click ENTER THE EXPERIENCE.

The full Black & Gifted MP3 soundtrack is embedded directly inside index.html.
This removes the Windows/Python ConnectionResetError path entirely.

If the game encounters a JavaScript runtime error, it will now display the error
inside the browser window rather than silently leaving you on a dead screen.
