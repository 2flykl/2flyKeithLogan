I WAS AWAY — GODOT PROTOTYPE

WHAT'S INCLUDED
- Open outdoor environment with rolling terrain, lake, distant mountain ring and atmosphere
- Two simple placeholder people: Player and Instructor
- Mouse-drag orbit camera
- Mouse-wheel zoom
- Working 3D boomerang throw-and-return loop
- Auto orbit toggle
- Placeholder visibility toggle
- Web-friendly Godot renderer setting

HOW TO OPEN
1. Install Godot 4.x (standard build is fine).
2. Extract this ZIP.
3. In Godot Project Manager choose Import.
4. Select project.godot inside the I_Was_Away_Godot_Prototype folder.
5. Open the project and press F6/F5 or the Play button.

CONTROLS
- Left mouse drag: orbit around the scene
- Mouse wheel: zoom
- Space: throw boomerang
- R: reset camera
- On-screen buttons provide the same key actions plus auto-orbit and placeholder toggle.

IMPORTANT
This is an architecture/prototype build. The placeholder people and procedural landscape are intentionally simple. The next production step would replace them with your actual sprite sheets and a photographic/scanned/AI-generated environment treatment, while keeping the Godot camera and gameplay logic.

WEB EXPORT
This project is configured for Godot's Compatibility renderer to keep the path open for HTML5/Web export. Export templates are not bundled; install them from Godot's editor when you are ready to export.
