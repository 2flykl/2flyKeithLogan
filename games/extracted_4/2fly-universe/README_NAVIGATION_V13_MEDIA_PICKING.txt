2fly Universe Navigation V13 — Reliable Media Picking

Fixes:
- Orbit media can be selected from normal viewing distance.
- Picking uses normal 3D raycast first, then a screen-space tolerance around visible orbit objects.
- First click selects/highlights and shows identity.
- Second click on the same selected media item opens/starts the content.
- Passing through/near orbit objects does not activate content.
- Empty-space click still clears selection.
- Existing travel hints, selector circle, orbit, and right-mouse thruster behavior are retained.
