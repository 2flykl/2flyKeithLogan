# What NOT to do on Day 1

Do not:
- connect every subscription account immediately
- grant Unrestricted machine access
- tell an agent "fix/polish everything"
- let multiple write-capable agents edit the same files in parallel
- delete "duplicate-looking" game folders
- deploy to production
- paste OAuth secrets into repository files
- let agents reorganize Google Drive
- connect Unreal to the website workspace
- treat browser automation as proof of permission under a third-party service's terms

Day 1 goal:
Create the Project, connect GitHub + Chrome, load the agent pack, and produce a verified audit.
