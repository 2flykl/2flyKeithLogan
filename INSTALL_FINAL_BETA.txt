2Fly Final Beta 3.3 Installation

1. Open GitHub Desktop and select the 2flyKeithLogan repository.
2. Commit and push any unfinished work.
3. Choose Repository > Show in Explorer and copy the repository folder somewhere safe as a backup.
4. Extract the Final Beta 3.3 ZIP.
5. Open 2fly_Final_Beta_3_3_Package.
6. Open COPY_TO_2flyKeithLogan_ROOT.
7. Copy everything inside that folder.
8. Paste the files directly into the root of the local 2flyKeithLogan repository.
9. Choose Merge folders and Replace files in the destination.
10. Return to GitHub Desktop.
11. Commit with: Install Final Beta 3.3 — Playable Carousel Scale Repair
12. Click Push origin.
13. Wait 1–3 minutes for GitHub Pages.
14. Open https://2flykl.github.io/2flyKeithLogan/?finalbeta=3.3
15. Press Ctrl + Shift + R once.

Do not paste this package into the separate 2fly-final-beta Render project.
