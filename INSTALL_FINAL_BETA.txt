2FLY FINAL BETA 3.6 — INSTALLATION DIRECTIONS

1. Open GitHub Desktop.
2. Select the 2flyKeithLogan repository.
3. Commit and push any unfinished changes before installing this revision.
4. Choose Repository > Show in Explorer.
5. Copy the entire repository folder somewhere safe as a backup.
6. Extract 2fly_Final_Beta_3_6_Final_Composition_and_Title_Lock.zip.
7. Open 2fly_Final_Beta_3_6_Package.
8. Open COPY_TO_2flyKeithLogan_ROOT.
9. Copy everything inside that folder.
10. Paste the copied files directly into the root of the local 2flyKeithLogan repository.
11. Choose Merge folders and Replace files in the destination when prompted.
12. Return to GitHub Desktop.
13. Commit with:

    Install Final Beta 3.6 — Final Composition and Title Lock

14. Click Push origin.
15. Wait approximately 1–3 minutes for GitHub Pages to rebuild.
16. Open:

    https://2flykl.github.io/2flyKeithLogan/?finalbeta=3.6

17. Press Ctrl + Shift + R once on Windows.
18. On a phone, close the previous browser tab completely and reopen the site.

IMPORTANT
- Install this package only in the GitHub Pages 2flyKeithLogan repository.
- Do not paste it into the separate Render project named 2fly-final-beta.
