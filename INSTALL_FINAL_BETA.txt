2FLY FINAL BETA 3.8 — INSTALLATION DIRECTIONS

1. Open GitHub Desktop and select the 2flyKeithLogan repository.
2. Commit and push any unfinished changes.
3. Choose Repository > Show in Explorer and make a backup copy of the repository folder.
4. Extract the Final Beta 3.8 ZIP.
5. Open 2fly_Final_Beta_3_8_Package.
6. Open COPY_TO_2flyKeithLogan_ROOT.
7. Copy everything INSIDE that folder.
8. Paste the files into the root of your local 2flyKeithLogan repository.
9. Choose Merge folders and Replace files in the destination.
10. In GitHub Desktop, commit with:
    Install Final Beta 3.8 — Unanchored Pay What It’s Worth
11. Push origin.
12. After GitHub Pages rebuilds, open:
    https://2flykl.github.io/2flyKeithLogan/?finalbeta=3.8
13. Press Ctrl + Shift + R once.

WIX LINK REQUIRED
Open js/app.js and replace:
PASTE_YOUR_WIX_PAYMENT_PAGE_URL_HERE
with the published URL of your Wix custom-price payment page.

Example:
const WIX_PAY_WHAT_ITS_WORTH_URL='https://www.2flykeithlogan.com/pay-what-its-worth';

The website adds these query parameters automatically:
?amount=25.00&project=Thru%20the%20Fire

Do not paste this package into the separate Render project named 2fly-final-beta.
