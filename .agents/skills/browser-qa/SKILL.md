# Browser QA

Use Chrome/browser tooling rather than code inspection alone.

Check:
- route loads
- critical assets resolve
- console
- network failures
- viewport overflow
- navigation
- primary CTA
- gameplay start
- keyboard/pointer/touch behavior when applicable
- audio behavior when applicable
- restart/replay when applicable

Representative viewports:
360x800, 390x844, 430x932, 1366x768, 1920x1080.

Capture evidence for failures and material visual fixes.
