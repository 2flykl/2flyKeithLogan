# Ebony Eyes — Gameplay Contract

- Board starts empty.
- Highlighted tile is the player's cursor/location, not an icon carrier.
- Icons descend lane-by-lane one grid space at a time.
- Player navigates among tiles.
- Space locks the icon currently occupying/passing the highlighted tile.
- Space also unlocks a locked tile.
- Matching adjacent icons form connections.
- A connected pair may remain while the player waits for a third.
- Player may lock multiple tiles.
- Falling/stacking pressure creates a Tetris-like risk/reward layer.
- Red balloon hazard can clear/push accumulated tiles and may remove a locked tile it reaches.
- If one tile in a pair is removed, the remaining tile persists.
- An icon reaching the final row is removed on the next movement; that icon type may spawn again later.
- Generator must avoid obvious repetition while still creating fair opportunities.
- Difficulty increases progressively with the song.
- Entire game should fit the gameplay viewport without page scrolling.
- Human emoji representations should use Black/African-American skin tones rather than default yellow.
